# Custom alternative political atlas

**Current edition:** [48 districts across 12 divisions, with updated fictional statistics](punjab-final-divisions-and-statistics.md), revision 2026-10-15. Amb is a separate Union Territory; there are 43 state/province/UT profiles. Rawalpindi has five districts and Hazara has three; the other ten divisions retain their assignments and boundaries. Punjab's user-defined fictional population is 7 crore. See the current record for environmental estimates, regeneration and validation commands. The earlier construction and population notes below describe prior snapshots; their district/province totals, population models and scaffold regeneration commands are superseded.

Open **My maps → United Subcontinent — Alternative Political Geography → Open custom map**. The atlas opens directly without a password, session cookie, lock button or access timeout. Opening and closing it preserves the editor draft and the saved-map library. Its overview, research and paged detail API are available without authentication.

## Local operation

Use `npm run build:vercel` and `npm run preview:vercel -- --host 127.0.0.1 --port 4545`. The Vite server and preview mount `/api/private-atlas`; ordinary static hosting cannot serve the atlas API. Development supports this API too.

The dataset remains encrypted in `server/private-atlas.enc` to preserve the existing storage and regeneration workflow. Only `PRIVATE_ATLAS_DATA_KEY` is required on the server, in ignored `.env.local` locally. Password hashes and session secrets are no longer used. Keep the data key out of client code and Git. Encryption at rest does not restrict map access: anyone using the server-enabled application can load this custom atlas. Origin checks and input validation remain in place.

## Vercel deployment

`api/private-atlas.mjs` is a Node function included by the existing Vercel build. Set the existing `PRIVATE_ATLAS_DATA_KEY` as a server-side Secret environment variable; the encrypted dataset is included by `vercel.json`. `PRIVATE_ATLAS_ORIGIN` can optionally pin the application origin. No password or session environment variables are required. The app reports an unavailable atlas if its data key or dataset is missing. Existing public source datasets remain unchanged.

## Editorial inputs and regeneration

Private editorial inputs, builder, photograph metadata, build output and geometry audit live in ignored `private/united-atlas/`. Preserve them for future editing. The reviewed `profiles.json` is the canonical editorial input; `profiles.py` is its initial scaffold and should not overwrite reviewed prose. `scripts/build-private-atlas.py` runs the private builder to derive source assignments, district splits, divisions, the 72-tehsil KP review, administrative table and exact geometry. It uses Shapely 2.1 and GeographicLib from the project-local geometry runtime. Run the private `refine.py`, `repair-precision.py`, `areas.py` and `correct-districts.py`, then `scripts/regroup-private-atlas.py`, followed by private `include-shaksgam.py` and `finalize.py`. Apply the tracked district update step described below, then run private `compact.py`. The regrouping script is idempotent and preserves a private backup of the earlier 43-province dataset. The finished atlas has 42 provinces, states and union territories. These steps reconcile source-edition seams, normalise shared polygon precision, calculate ellipsoidal areas, validate district splits, attach sourced city/heritage points and verify finished coverage and response sizes. Preserve their topology and audit outputs with the private inputs.

After private `finalize.py`, run `scripts/update-private-atlas-districts.py` with the project Python 3.12 geometry runtime, then private `compact.py`. This tracked, repeatable step merges full Attock into Panja Sahib, separates Taxila from Rawalpindi, combines the requested Haripur, Harappa and Sangrur districts, and applies the requested district names. `scripts/punjab-tehsil-heritage-names.json` records the user's reviewed names, meanings and short histories for 180 source tehsils. A further 32 sourced locality and heritage choices implement the later rename request; Soon and Ramnagar were subsequently restored to Naushera and Wazirabad at the user's request. Sixty labels now differ from the original source names. The omitted official Guru Har Sahai tehsil is reconstructed as a 181st feature from Ferozepur district area left uncovered by the source layer. Several unassigned strips inside Lahore district are joined to the adjacent Lahore tehsils with which they share the longest border. These are approximate cartographic repairs, not independently surveyed tehsil boundaries. The sidebar attributes naming descriptions to the supplied review, linked sources or the Ferozepur district source and shows geometry adjustment notes. Original source names and identifiers remain available for audit. Run the step again after any full private rebuild.

`scripts/punjab-divisions.json` records the eleven requested Punjab divisions, their headquarters and their 49 source district records. The default map and statistics combine Chakwal into Katas and Narowal into Kartarpur Sahib, displaying 47 districts. The district update step unions member district polygons and updates each district, tehsil and research row. It calculates WGS84 ellipsoidal division and district areas, Punjab area shares and mapped tehsil counts. `scripts/punjab-division-profiles.json` holds editorial previews, real headquarters city identities, source links and image references; `scripts/punjab-division-photos.json` retains Commons metadata for the Harappa and Amb temple photographs. Other images reuse the attributed shrine and province photo registries. Headquarters points use the existing Natural Earth city catalogue plus linked Wikidata coordinates for Mohali and Bathinda. The sidebar lists district area, district population, division area and division population rankings in that order, followed by a top-ten religion selector and an alphabetical district directory. Population ranks use the explicitly fictional model below. All district statistics, profiles and division counts follow the same displayed merges and local renames as the map. Clicking a polygon, headquarters marker or sidebar entry opens its profile. Keep these inputs alongside the name registry when rebuilding the encrypted atlas.

Punjab districts use the 45 named pastel colors in `app/private-atlas-districts.ts`, assigned in district name order and repeated after color 45. In the tehsil view, **Color by district** gives each tehsil its parent district's color and draws the district outlines; **Color by tehsil** assigns the same palette independently in tehsil name order. Select an area to choose a named palette color or a custom fill. Existing per-district color edits remain available in both views. Satellite imagery keeps polygon fills transparent and shows the boundaries.

`scripts/private-atlas-photos.mjs` records Commons author/license metadata and preserves reviewed galleries from private `curated-photos.json`; reusable existing shrine photos retain their original attribution. Punjab has five attributed photographs: the Golden Temple illuminated at night, Nankana Sahib, Lahore Fort, Murree and Kartarpur Sahib. Its three proposed official languages are Punjabi (Gurmukhi), Hindi and Urdu; the designation applies only to this fictional scenario. The visible infobox omits flag/emblem and area-method fields, while measurement provenance remains in Research & changes. `node scripts/pack-private-atlas.mjs` encrypts the reviewed payload using the server data key. Verify with `npm run check:private-atlas` and `npm run check:private-atlas-browser`. Browser checks use an isolated storage profile and do not alter the user's saved maps.

Province ownership is a fictional partition of retained source editions. The province overview uses shared-edge simplification; finer outlines load through paged requests and replace all province outlines together so neighbouring edges remain aligned. District/tehsil detail is paged through authenticated requests. Source identity, geometry hashes, census year, ownership priority, overlap adjustments and unavailable administrative coverage appear in **Research & changes**. Exact WGS84 polygon area includes source inland waters and is not a verified dry-land-only figure. Forest statistics remain unavailable until a defensible matched aggregation exists. Indian 2011 and Pakistan 2023 populations are not combined into a misleading single-year total.

User-defined populations belong in the optional `hypotheticalDemographics` profile field, separate from real-world `population` and `census`. The packer validates nonnegative integer community counts and derives their total. The panel labels these values as hypothetical and displays lakh/crore counts, calculated shares and scenario density. These editorial values stay in the encrypted private payload.

### Fictional Punjab population model

`scripts/punjab-population-model.mjs` defines the scenario's settlement sizes and religious distribution. Punjab retains 79,600,000 residents: 61,000,000 Sikh, 16,000,000 Hindu, 1,700,000 Muslim, 400,000 Christian, 200,000 Jain, 150,000 Buddhist and 150,000 other residents. The earlier settlement weights preserve each source district's total. The model varies religious weights by district, balances both district and province totals, then rounds to whole residents with a minimum-cost allocation that preserves every total exactly. Merged district profiles sum all member counts, and division profiles aggregate those displayed districts.

Taxila has the largest Buddhist population and share, with secondary concentrations in Haripur and Rawalpindi. Katas Raj and surrounding Chakwal have a substantial Hindu community. Amritsar, Kartarpur Sahib, Nankana Sahib, Sri Anandpur Sahib, Tarn Taran, Sandalbar and Lahore have strong Sikh majorities, with Lahore and Sandalbar the largest Sikh populations. Other districts retain varied rural or urban mixtures; Sangrur's Muslim allocation accounts for its retained Malerkotla area, while larger Christian and Jain allocations appear in selected urban districts. Each district's scenario note explains its emphasis.

Heritage associations are checked against [UNESCO's Taxila record](https://whc.unesco.org/en/list/139/), [Punjab's archaeological-site guide](https://punjab.gov.pk/archeological-sites), the [Department of Archaeology's Katas Raj entry](https://doam.gov.pk/public/sites/6750), and [Malerkotla's district history](https://malerkotla.nic.in/history/). These references describe heritage; all population weights and counts are fictional editorial choices rather than historical or modern census estimates.

Regenerate with `npm run data:punjab-district-profiles`, run `npm run check:punjab-district-profiles`, then `node scripts/pack-private-atlas.mjs` using the existing server data key. Restart the local preview after repacking because its API caches the decrypted dataset. Run `npm run check:private-atlas`, `npm run check:punjab-rankings-browser` and `npm run check:punjab-district-profiles-browser` to verify the encrypted API, religious concentrations, exact totals, all 47 displayed profiles, ranking filters and mobile layout.

United Jammu and Kashmir combines the previously allocated JK, AJK and Gilgit-Baltistan polygons with the existing Natural Earth Siachen polygon. Ladakh–Aksai Chin combines the previously allocated Ladakh outline with the existing Aksai Chin source polygon. The two unions use shared polygon edges; Siachen is assigned to the Kashmir province, and Aksai Chin takes priority over a small GB source-edition overlap. Current administration and disputed-boundary references remain available independently. Shaksgam Valley (called Shaksam Valley in the retained source) is also assigned to United Jammu and Kashmir by unioning the existing Natural Earth polygon; its current-administration context remains available. These are fictional cartographic choices, not surveyed control lines or a resolution of territorial disputes. Unverified district/tehsil coverage in Siachen, Shaksgam Valley and Aksai Chin remains explicitly unavailable. Retained Indian states outside the redesign use their source outlines. The national view initially shows only provinces, states, UTs and capitals; district and tehsil boundaries are optional detail views.

Run `npm run check:punjab-division-profiles-browser` for the focused eleven-division check: profile statistics, attributed photographs, headquarters and polygon clicks, full division export, and mobile layout.
