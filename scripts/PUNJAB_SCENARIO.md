# Punjab district population scenario

This is an authored alternative-world case study, not a census, prediction or assessment of real communities. The province has 79,600,000 fictional residents: 61,000,000 Sikh, 16,000,000 Hindu, 1,700,000 Muslim and 900,000 other residents. The last group is illustratively split into 400,000 Christian, 200,000 Jain, 150,000 Buddhist and 150,000 other residents.

`build-punjab-district-profiles.mjs` apportions each religion separately across the 49 canonical proposed districts using the largest remainder method. Named urban districts receive editorial settlement weights; remaining districts use bounded mapped-area weights. Western districts receive a higher Sikh multiplier; eastern districts receive a higher Hindu multiplier. This guarantees exact integer totals and produces a Sikh majority in both regions. Lahore receives the largest settlement weight. Density divides the fictional allocation by mapped area. No development index or actual city population is inferred.

Geographic introductions are adapted from linked Wikipedia articles. Wikimedia Commons galleries include author, license, source link, source retrieval date and documented capture dates. Search results are checked for location relevance. Recent upload dates do not establish recent capture dates; the interface does not promise that the images are the latest photographs taken. Proposed district geography may differ from the real source article.

After regenerating district geometry, run `node scripts/build-punjab-district-profiles.mjs`, then `node scripts/check-punjab-district-profiles.mjs` and `node scripts/pack-private-atlas.mjs`. Checked source metadata is cached in `punjab-district-references.json`; review those entries before deliberately refreshing them. `curate-punjab-district-references.mjs` records explicit locality corrections, selects reviewed landmarks and supplements sparse galleries using verified source files. Capture dates vary, and one sparse district gallery includes an explicitly dated historical photograph. Build the frontend and verify the profiles with `node scripts/verify-punjab-district-profiles.mjs` against the local preview.
